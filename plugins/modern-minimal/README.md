# Modern Minimal Theme

现代简约风格主题，专为个人博客和作品集设计。

## 特性

- 🎨 **干净优雅** - 极简主义美学，专注于内容
- 📱 **完全响应式** - 完美适配桌面、平板和手机
- 🌓 **自动深色模式** - 根据系统偏好自动切换
- ⚡ **性能优化** - 懒加载图片、平滑滚动
- 🎯 **SEO 友好** - 语义化 HTML 结构

## 安装

将主题文件夹复制到 `plugins/` 目录，在管理后台激活即可。

## 配置

编辑 `theme.config.js` 自定义颜色、布局和功能开关。

## 适用场景

个人博客 · 作品集展示 · 技术文章 · 生活随笔 · 创意写作
